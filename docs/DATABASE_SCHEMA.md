# DATABASE SCHEMA

Database Engine: **MongoDB** (`mongodb://localhost:27017/water_leak_detection`)

## Collections & BSON Schemas

### 1. `telemetry` (Collection)
Stores 1Hz sensor readings from physical rig or simulated MQTT publisher.
```json
{
  "_id": "ObjectId(...)",
  "ts": 1754131200,
  "seq": 1042,
  "q_in_lpm": 4.50,
  "q_out_lpm": 4.40,
  "q_branch_lpm": 0.00,
  "current_ma": 830.0,
  "voltage_v": 11.9,
  "pressure_bar": 2.45,
  "raw_pulses_in": 4560,
  "raw_pulses_out": 4480,
  "solenoid_state": 0,
  "created_at": "2026-08-03T09:45:00.000Z"
}
```
**Indexes**:
- `{ ts: -1 }` (Descending timestamp index for fast 1Hz range scans)

---

### 2. `leak_events` (Collection)
Ground truth records of injected leaks during experimental test runs.
```json
{
  "_id": "ObjectId(...)",
  "start_ts": 1754131260,
  "stop_ts": 1754131285,
  "location_node": "Branch_A (Side Loop Node 3)",
  "severity_lpm": 1.25,
  "is_ground_truth": true,
  "notes": "Manual solenoid valve open injection test"
}
```

---

### 3. `detections` (Collection)
Alert outputs generated by multi-method detection algorithms and sensor fusion.
```json
{
  "_id": "ObjectId(...)",
  "ts": 1754131262,
  "method": "Mass Balance Residual (3-Sigma)",
  "confidence": 0.94,
  "residual": 1.23,
  "is_alarm": true,
  "leak_event_id": "ObjectId(...)"
}
```
**Indexes**:
- `{ ts: -1 }`
- `{ is_alarm: 1, ts: -1 }`

---

### 4. `experiment_runs` (Collection)
Metadata for benchmark replay datasets (`RUN_001` - `RUN_012`).
```json
{
  "_id": "RUN_001",
  "operator": "Manoj",
  "date": "2026-08-03",
  "leak_size_lpm": 0.50,
  "leak_location": "Branch_A",
  "pump_mode": "constant",
  "notes": "Micro-leak sensitivity baseline test"
}
```

---

### 5. `work_orders` (Collection)
Field repair crew work orders generated by CP-SAT optimization.
```json
{
  "_id": "WO-2026-001",
  "leak_event_id": "ObjectId(...)",
  "location_node": "Branch_A (Side Loop)",
  "severity_lpm": 1.25,
  "priority": "HIGH",
  "assigned_crew": "CREW_ALPHA",
  "scheduled_start": "2026-08-03T11:00:00.000Z",
  "estimated_hrs": 1.8,
  "status": "DISPATCHED"
}
```
